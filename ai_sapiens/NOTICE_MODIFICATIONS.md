# Modifications to ROBOTIS ai_sapiens files (Apache-2.0, Section 4(b))

Source: https://github.com/ROBOTIS-GIT/ai_sapiens (`ai_sapiens_description`), Apache License 2.0,
upstream commit `bdc40f126c4a1551422dce44dce144974f7a2f2b` (the commit used for all experiments; pinned in
`scripts/fetch_external.sh`). Only the files needed for this project are included.

## Unmodified copies
`mujoco/k1/k1.xml`, `mujoco/k1/scene.xml`, `urdf/k1_rev1/k1.urdf`, `meshes/k1_rev1/*.stl` with their original names
are byte-identical copies of the upstream files (git blob SHA identical). `k1.urdf` still contains the upstream xacro
header with ROBOTIS' build path; it is left untouched on purpose (unmodified copy).

## Derived (modified) files — Takeyuki-K, 2026
All derived files are generated by `k1_mp/gen_model.py` (re-running it reproduces them byte for byte).
The XML / URDF files carry a modification notice in their header; STL files cannot carry comments and are listed here.

| original upstream file | derived file | modification |
|---|---|---|
| `mujoco/k1/k1.xml` | `mujoco/k1/k1_mp.xml` | foot split at the MP (toe) plane; passive MP joints (torsional spring 2.63 Nm/rad, damping); new foot contact geometry (heel capsule, metatarsal capsule, toe pad); toe link mass / inertia, ankle link mass reduced by the toe mass; MP joint position sensors; keyframe extended |
| `mujoco/k1/scene.xml` | `mujoco/k1/scene_mp.xml` | includes `k1_mp.xml` instead of `k1.xml`; model name; floor friction set explicitly |
| `urdf/k1_rev1/k1.urdf` | `urdf/k1_rev1/k1_mp.urdf` | same model changes as `k1_mp.xml`; upstream xacro header (build path) replaced by the modification notice |
| `meshes/k1_rev1/left_ankle_roll_link.stl` | `meshes/k1_rev1/left_ankle_roll_link_rear.stl` | mesh cut at the MP plane, rear (heel) part |
| `meshes/k1_rev1/left_ankle_roll_link.stl` | `meshes/k1_rev1/left_toe_link.stl` | mesh cut at the MP plane, front (toe) part, expressed in the toe-joint frame |
| `meshes/k1_rev1/right_ankle_roll_link.stl` | `meshes/k1_rev1/right_ankle_roll_link_rear.stl` | as left |
| `meshes/k1_rev1/right_ankle_roll_link.stl` | `meshes/k1_rev1/right_toe_link.stl` | as left |

Training environments add further run-time changes in code (not in these files): touch-sensor sites, actuator
configuration (PD / variable impedance), assist actuators for curricula, domain randomisation. They are documented in
the respective `k1env*.py` files.
